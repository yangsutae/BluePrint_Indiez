# BluePrint Indiez 랜딩페이지 — 2D 캔버스 판

> `../_archive/260928-landing/`(이전 최종본, CSS 3D 판)과 장면·문구·동작이 같고, 캐비닛을 그리는 방식만 다르다. 원본은 면 319개를 div + CSS 3D 변환으로 쌓아 브라우저 하드웨어 가속이 꺼지면 화면이 깨질 수 있었다. 이 판은 animejs.com처럼 2D 캔버스에 직접 그린다: 면을 좌표로만 들고 원근(1700px)·앞뒤 순서·명암을 `js/lowpoly.js`가 계산한다. 페이지 어디에도 CSS 3D 변환(`preserve-3d`, `translate3d` 등)이 없다.
>
> - 캐비닛·선 입체·K0 입체도: `<canvas>` (무대 전체 `#cv`, 입체도 `#isoCv`)
> - 3면도 그림: SVG 그대로, 모델과 함께 도는 구간은 2D `matrix()`로 근사 (`BPI.planeMatrix`, 정면 각도에서는 정확히 겹침)
> - 부품 강조 흐림(0.35초 전환)·80% 투명도·흰 외곽선·빛 번짐: 캔버스에 그릴 때 줌
> - 확인(2026-10-02): GPU를 끈 Edge에서 장면 7곳을 원본과 나란히 캡처해 같은 모습, 스크립트 오류 없음


> 최종본. K2~K5 구간은 D6 방식(한 번에 분해 → 카메라가 부품 하나씩 확대·포커싱)으로 바꾸고, 포커스 중에는 카메라 확대로 모든 사물이 1.5배, 포커스된 부품만 2배로 보인다. 포커스 구간은 스크롤을 2.2배 더 쓴다. 제작 과정은 `../작업과정_명세서.md`.
>
> 3D 모델은 모든 면에 흰색 외곽선. 부품 장면은 제목 카드(중제목·대제목·설명, 글자 1.7배)와 전개도 칸을 한 묶음으로 오른쪽 열 세로 가운데에 두고, 스크롤에 따라 천천히 나타나고 사라짐.
> 부품 글 읽는 구간에서는 장면이 스크롤의 약 30% 속도로만 진행(마찰 구간, `js/landing.js`의 `FRICTION`·`ZONE`). 방향키 ↑↓와 PageUp/PageDown은 한 번 누르면 다음·이전 멈춤 지점(도면 → 3D 완성 → 부품 4개 → 마지막 장면 → 함께하기)까지 누르는 즉시 장면이 움직이기 시작(화면이 멈춰 있는 구간은 건너뜀), 가속 10%·등속·감속 30%. 지점과 지점 사이 1.6초(`js/landing.js`의 `SEGMENT_MS`로 조절), 이동 중 다시 누르면 가속 없이 이어서 이동, 이동 중 마찰 없음, 휠·터치하면 멈춤.

최종 시안(키프레임 8장)을 스크롤로 이어지는 한 장짜리 작동 페이지로 만든 것. 이 폴더 그대로 웹 서버(GitHub Pages, Netlify 등)에 올리면 된다. 빌드 과정 없음.

## 동작

- 데스크톱: 화면이 고정된 채 스크롤 진행률(0~1)에 따라 장면이 바뀜. 1440×900 무대를 창 크기에 맞춰 확대·축소.

| 진행률 | 장면 |
|---|---|
| 0 ~ 0.06 | K0 도면 (로고·3면도·입체도·표제란, 로드 시 선 그리기) |
| 0.06 ~ 0.18 | 3면도째 회전하며 정면도에서 깊이가 자라나 입체로 섬 (D6 방식), 가운데로 이동 |
| 0.13 ~ 0.24 | 선 입체 위로 면이 채워지고, 정면도 선·보조 도면이 사라짐 |
| 0.26 ~ 0.31 | 가운데에서 첫 포커스 위치로 곧장 이동하며 네 부품이 한 번에 분해 |
| 0.30 ~ 0.70 | K2~K5 부품 하나씩 포커싱(포커스 부품 2배·나머지 1.5배, 나머지 흐림) + 전개도 + 설명 (간판 — 이름 · 화면 — 주제 · 조작부 — 참여 · 동전 투입구 — 함께하기) |
| 0.70 ~ 0.74 | 카메라가 물러나며 부품이 다시 붙음 |
| 0.70 ~ 0.80 | 부품이 모두 붙은 캐비닛이 K7 자리로 (K6 도면 장면은 삭제) |
| 0.72 ~ 1 | K7 각도 링 위 천천히 회전 + 큰 로고·공지방 버튼·"BPI 자세히 보기"(`/main/`)·참여 QR, 왼쪽 아래 와이어프레임 ON/OFF |

- 아래 가운데 점: 장면 바로가기. 맨 아래 "함께하기" 영역은 항상 있음(키보드 "함께하기로 바로 가기" 링크 포함).
- 좁은 화면(폭 820px 이하 또는 높이 520px 이하): 스크롤 연출 대신 로고·소개·선 입체 그림·K2~K5 문구 네 덩어리·버튼 2개를 세로로 보여 줌.
- 동작 줄이기 설정: 선 그리기·자동 회전 없음(스크롤 변화는 유지).
- 3D 모델은 투명도 80%(면마다 적용).
- 진행률은 장면 기준. 포커스 구간(0.30~0.70)은 스크롤을 2.2배 더 써서 천천히 넘어감.
- 확인용 주소 값: `?p=0.5` → 그 진행률로 고정, `?wf=1` → 와이어프레임 켠 채 시작.

## 수정할 곳

- 문구: `index.html`(K0·K7·모바일·하단), `js/parts.js`(부품 설명)
- 링크: 카카오톡 공지 채팅방 `https://invite.kakao.com/tc/2BYLO0beM5` — `index.html` (K7·모바일·하단). `js/parts.js`의 `items`에도 남아 있으나 화면에는 쓰이지 않음. 본사이트 `/main/` 링크 — K7 보조 버튼·모바일 보조 버튼·하단 "자세히 보기" (지금은 비활성화: `href` 대신 `data-href`, `aria-disabled="true"`. `/main/` 배포 후 `data-href`를 `href`로 바꾸고 `aria-disabled` 삭제). 이메일 문의·행사 정보는 넣지 않음
- 문구 기준: `../본페이지_및_랜딩_구성안.md` §3.2 장면별 문구 (2026-10-02 반영)
- 참여 QR: `assets/kakao_qr.svg` (위 링크와 같은 주소, `발표/포럼_소개/assets/kakao_qr.svg`에서 복사). K7 마무리의 버튼 옆에만 있고(안내 문구 없음), 좁은 화면에서는 숨김. 링크를 바꾸면 QR도 다시 만들어야 함
- 장면 길이: `css/landing.css`의 `.hero { height: 1300vh }`, 포커스 구간(0.30~0.70)은 `js/landing.js`의 `FOCUS_SLOW`(2.2배)로 스크롤을 더 씀. 장면 구간은 `TRACK`·`PART_SEG`와 `render()`
