# BluePrint Indiez 랜딩페이지 (최종본)

> 최종본. K2~K5 구간은 D6 방식(한 번에 분해 → 카메라가 부품 하나씩 확대·포커싱)으로 바꾸고, 포커스 중에는 카메라 확대로 모든 사물이 1.5배, 포커스된 부품만 2배로 보인다. 포커스 구간은 스크롤을 2.2배 더 쓴다.

최종 시안(키프레임 8장)을 스크롤로 이어지는 한 장짜리 작동 페이지로 만든 것. 이 폴더 그대로 웹 서버(GitHub Pages, Netlify 등)에 올리면 된다. 빌드 과정 없음.

## 파일

```
260928-landing/
  index.html          페이지 (진입점)
  css/base.css        색·선·시트·3D 면 스타일
  css/landing.css     페이지 배치·스크롤 무대·모바일
  js/lowpoly.js       로우 폴리 아케이드 캐비닛 (CSS 3D)
  js/sheet.js         시트 테두리·3면도·전개도·선 그리기
  js/parts.js         부품별 문구 (간판·화면·조작부·동전 투입구)
  js/landing.js       스크롤 연출
  assets/             로고(svg·png·pdf), 모바일용 선 입체 그림, 파비콘
```

## 동작

- 데스크톱: 화면이 고정된 채 스크롤 진행률(0~1)에 따라 장면이 바뀜. 1440×900 무대를 창 크기에 맞춰 확대·축소.

| 진행률 | 장면 |
|---|---|
| 0 ~ 0.06 | K0 도면 (로고·3면도·입체도·표제란, 로드 시 선 그리기) |
| 0.06 ~ 0.18 | 3면도째 회전하며 정면도에서 깊이가 자라나 입체로 섬 (D6 방식), 가운데로 이동 |
| 0.13 ~ 0.24 | 선 입체 위로 면이 채워지고, 정면도 선·보조 도면이 사라짐 |
| 0.26 ~ 0.31 | 가운데에서 첫 포커스 위치로 곧장 이동하며 네 부품이 한 번에 분해 |
| 0.30 ~ 0.70 | K2~K5 부품 하나씩 포커싱(포커스 부품 2배·나머지 1.5배, 나머지 흐림) + 전개도 + 설명 (동전 투입구에 공지 채팅방 링크) |
| 0.70 ~ 0.74 | 카메라가 물러나며 부품이 다시 붙음 |
| 0.70 ~ 0.80 | 부품이 모두 붙은 캐비닛이 K7 자리로 (K6 도면 장면은 삭제) |
| 0.72 ~ 1 | K7 각도 링 위 천천히 회전 + 큰 로고·함께하기 링크, 왼쪽 아래 와이어프레임 ON/OFF |

- 아래 가운데 점: 장면 바로가기. 맨 아래 "함께하기" 영역은 항상 있음(키보드 "함께하기로 바로 가기" 링크 포함).
- 좁은 화면(폭 820px 이하 또는 높이 520px 이하): 스크롤 연출 대신 로고·소개·선 입체 그림·주제·참여 방식을 세로로 보여 줌.
- 동작 줄이기 설정: 선 그리기·자동 회전 없음(스크롤 변화는 유지).
- 3D 모델은 투명도 80%(면마다 적용).
- 진행률은 장면 기준. 포커스 구간(0.30~0.70)은 스크롤을 2.2배 더 써서 천천히 넘어감.
- 확인용 주소 값: `?p=0.5` → 그 진행률로 고정, `?wf=1` → 와이어프레임 켠 채 시작.

## 수정할 곳

- 문구: `index.html`(K0·K7·모바일·하단), `js/parts.js`(부품 설명)
- 링크: 카카오톡 공지 채팅방 `https://invite.kakao.com/tc/2BYLO0beM5` 하나 — `index.html`과 `js/parts.js` 두 곳 (이메일 문의·행사 정보는 넣지 않음)
- 장면 길이: `css/landing.css`의 `.hero { height: 1300vh }`, 포커스 구간(0.30~0.70)은 `js/landing.js`의 `FOCUS_SLOW`(2.2배)로 스크롤을 더 씀. 장면 구간은 `TRACK`·`PART_SEG`와 `render()`
